                      Listas de coisas para aprender

## 1-Blender
- interface e navegação 3D (orbitar, zoom, seleção)
- primitivas e transformações (mover, rodar, escalar)
- modificadores básicos (bevel, mirror, array)
- materiais e render rápido

## 2-Gimp(2d)
- ferramentas de seleção (retângulo, laço, varinha)
- camadas e máscaras
- ajustar brilho/contraste/cor
- ficheiros e exportação (PNG, JPG)

## 3-Git e github
- git init / add / commit / status / log
- git branch / checkout / merge
- push / pull / clone (GitHub)
- .gitignore

## 4-Figma
- quadros iniciais, formas e texto
- componentes e auto-layout
- protótipo de clique (links entre ecrãs)
- exportar assets

## 5-Notion, obsidian
- blocos, páginas, bases de dados (Notion)
- Markdown, links entre notas, grafos (Obsidian)
- templates e atalhos principais

## 6-Escrita
- estrutura: introdução, desenvolvimento, conclusão
- frases curtas e claras
- revisão e edição
- escrita diária (rotina)

## 7-Sketching
- linhas e formas básicas
- sombras e luz
- proporções e perspetiva simples
- esboço diário (30 min)

## 8-Fotografia
- exposição: ISO, abertura, velocidade
- composição (regra dos terços, linhas-guia)
- luz natural
- edição básica (cor e recorte)

## 9-Da vinci resolve
- importar clips e timeline
- cortar/juntar clips
- transições e texto simples
- exportar vídeo

## 10-origami
- dobras básicas (vale, montanha)
- símbolos de diagrama
- 3 modelos fáceis (barco, avião, tulipa)
- 1 modelo médio

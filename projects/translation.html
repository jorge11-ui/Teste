Exponenciais

Funções Exponenciais

Uma função exponencial é uma função que possui a forma geral y = ax, onde "a" é qualquer constante maior que um. O gráfico de uma função exponencial aumentará a uma taxa crescente à medida que x aumenta, e terá também uma assíntota no eixo x, ou seja, aproximar-se-á do eixo x, mas nunca o tocará.

Outros exemplos de funções exponenciais incluem:
y = 10x
y = 53x
y = 52+x

Logaritmos

Uma função logarítmica é uma função que possui a forma geral y = loga(x). As funções logarítmicas aumentam infinitamente, mas a uma taxa decrescente, à medida que x aumenta. A função tem uma assíntota no eixo vertical, o que significa que se aproxima, mas nunca toca, o eixo y. Isto acontece porque não é possível calcular o logaritmo de um número negativo, portanto, o gráfico existe apenas para valores positivos de x.

A função y = log10(x) pode ser lida como "y é igual ao logaritmo na base 10 de x". Literalmente, o logaritmo é a quantidade numérica que representa o número de vezes que uma constante (a base, que aqui é 10) precisa de ser multiplicada por si mesma para chegar a outra quantidade (x).

Exemplo: quando x = 100:
y = log10(100) = 2

A Relação entre Exponenciais e Logaritmos

Para compreender um logaritmo, pode pensar nele como o inverso de uma função exponencial.

Se x = ay, então y = loga(x)

Exemplo: 8 = 23 ⇒ 3 = log2(8)

O Logaritmo Natural

A base mais comummente utilizada para logaritmos é a base e (≈ 2,718). Este é chamado de logaritmo natural e é escrito utilizando "ln".

loge(x) = ln(x)

Utilização de Logaritmos para Resolver Funções Exponenciais

Exemplo: 125 = 5x

ln(125) = ln(5x)
ln(125) = x ln(5)
x = ln(125) / ln(5) = 3
